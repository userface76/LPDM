# SSDM 생명살림 디지털 추모관

Saengmyeong Sallim Digital Memorial Hall

제1호 금송 양홍관 선생 디지털 추모관을 시작으로 삶의 기록을 보존하는 공익형 플랫폼입니다.

## 배포
Cloudflare Worker: `lpdm-web`

```bash
npm install
npm run deploy
```

현재 SSDM V2 홈페이지의 카테고리와 인물별 추모관 검색 화면을 제공합니다. 추모글 및 자료 업로드 기능은 승인·권한 검증 시스템을 구축한 이후 공개합니다.


## 메인 배경 이미지 교체 안내

- 메인 배너 URL: `/ssdm-main-hero.webp`
- 저장소 업로드 경로: `public/ssdm-main-hero.webp`
- **권장 크기: 1920 × 1080 px, 가로형 16:9**
- 고해상도 이미지: 2400 × 1350 px, 가로형 16:9
- 권장 포맷: **WebP**, sRGB, 300~700KB 이내 (대안 JPG)
- 기존 파일과 같은 이름으로 GitHub에서 교체하면 소스 수정 없이 새 배경으로 변경됩니다.
- 메인 문구와 버튼은 이미지에 합성하지 않고 웹페이지에서 별도로 렌더링합니다.
- PC: 화면을 가득 채우도록 `background-size: cover`, `background-position: center`.
- 모바일: `background-position: 63% center`; 화면이 좁으면 가장자리가 일부 잘립니다.

### 주요 이미지 크기 표준

| 용도 | 권장 해상도 | 비율 |
|---|---|---|
| 메인 배경 | 1920×1080 | 16:9 |
| 내부 페이지 배너 | 1600×600 | 8:3 |
| 추모관 목록 카드 | 1200×800 | 3:2 |
| 개인 대표사진 | 1200×1500 | 4:5 |
| 갤러리 사진 | 1600×900 | 16:9 |
| 기관 로고 | 가로형 PNG, 투명 배경, 1140×344 원본 유지 | 약 3.3:1 |

> 소나무·안개 풍경 원본은 1672×941px이며 16:9 배너에 가까운 비율입니다.
